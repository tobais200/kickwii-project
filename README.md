# kickwii-proyect
Unofficial Kick.com client for the Nintendo Wii (homebrew). Browse live streams, categories and channels, watch live streams, and read live chat directly from the Wii with a Kick-style interface. Installs as a Wii Menu channel (WAD) or a Homebrew Channel app.

## Languages

The interface is available in 11 languages: English, Spanish (Español), French (Français), German (Deutsch), Italian (Italiano), Dutch (Nederlands), Portuguese – Brazil (Português), Japanese (日本語), Simplified Chinese (简体中文), Traditional Chinese (繁體中文) and Korean (한국어).

- The language is picked automatically from the Wii system language (Japanese, English, German, French, Spanish, Italian, Dutch, Simplified Chinese, Traditional Chinese and Korean map directly; any other console language falls back to English). Portuguese can be chosen manually.
- It can be changed at any time in **Settings → Interface language**; each language is listed under its own name. The choice is saved on the SD card (or USB) in `idioma-interfaz.txt`. The stream language filter (`idioma.txt`) is separate.
- The on-screen keyboard follows the interface language: ñ only on the Spanish layout, and an áé accent key for Spanish, French, German, Italian, Dutch and Portuguese.
- All strings live in one table (`wii-client/source/i18n_table.c`, generated by `wii-client/tools/i18n/gen.py`); translations were written without native review, so corrections are welcome.

### CJK font

The built-in UI font only covers Latin characters, so Japanese, Chinese and Korean use a small bitmap subset of **Noto Sans CJK** (Copyright Google / Adobe, licensed under the [SIL Open Font License 1.1](wii-client/licenses/NotoSansCJK-OFL-1.1.txt)), generated by `wii-client/tools/i18n/gen_cjk.py` and stored zlib-compressed. The glyphs for the app's own strings are unpacked only while a CJK language is active. A shared fallback of about 7,500 common characters covers Kick stream titles, channel names and chat in any interface language; anything still missing is drawn as a hollow box.
